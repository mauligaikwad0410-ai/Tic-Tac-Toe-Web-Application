# ❌⭕ Tic-Tac-Toe Game

A classic Tic-Tac-Toe game with a modern UI, built using HTML, CSS, and JavaScript.

## 🚀 Features
- Two-player mode
- Win & draw detection
- Reset game option
- Responsive layout

## 🛠️ Tech Stack
HTML5 • CSS3 • JavaScript

## 🎮 How to Play
- Players take turns (X & O)
- First to align 3 wins

## 📂 Setup
1. Clone the repo
2. Open `index.html`
